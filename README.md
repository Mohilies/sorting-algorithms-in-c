# sorting-algorithms-in-c
Selection_sort:
it works by moving thro the array and finding maximum number then putting it at n-i-1 then doing the same step n times 
bubble_sort:
moves thro the array and checks if left is smaller than right and if not it flips the elements . does this n² times and if no elements were exchanged in a single loop the function just exists 
quick_sort:
chooses the element at n-1-i as the pivot , then makes 2 variables i =0 and j =1 , then checks if element at j is smaller then pivot and if so it swaps j and i+1 and when the loop ends it swaps i+1 and n-1 which is the pivot
